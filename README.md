# Phishing URL Detector 🛡️

This is a **simple phishing URL detection software** built using Python and Tkinter.

It helps you check URLs for suspicious keywords, domain extensions, and other phishing indicators.

---

## Features ✨
- Detects suspicious keywords in URLs like `login`, `verify`, `account`, etc.
- Detects dangerous domain extensions like `.xyz`, `.top`, `.loan`, etc.
- Warns if raw IP is used instead of domain.
- Checks for suspicious domain length and hyphens.
- Simple and clean GUI interface.
- Windows `.exe` version included for easy usage.

---

## How to Download & Run ⬇️
1. Click on the **ZIP file** in this repository.  
2. Right-click → **"Save link as..."** → Save it to your PC.  
3. Extract the ZIP to any folder.  
4. Double-click `phishing_app_backup.exe` to run the software.

---

## Notes ⚠️
- This software is for **educational purposes only**.  
- Make sure you are using **Windows** to run the `.exe` file.  
- Do **not share sensitive personal data** while testing URLs.
